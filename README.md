# 群馬大学 吉原利忠教授 紹介ポータル

吉原教授（群馬大学大学院理工学府）の研究内容・経歴・最新文献を、第三者向けと教授向けの2モードで表示する単一ページアプリです。

## できること

- **第三者向けページ**
  - 教授プロフィール、研究テーマ、経歴ハイライトを見やすく表示
  - OpenAlex / Crossref から最新文献を自動取得して更新
  - 公開フォーム（Googleフォーム）でメッセージ受付
  - 公開スプレッドシート（CSV）から最新メッセージを自動表示
- **教授向け運用ページ**
  - OpenAlex Author ID / Crossref検索クエリをブラウザで設定
  - フォームURL、スプレッドシートURL、更新間隔を設定・保存
  - 第三者向け共有URLをワンクリックコピー

## 起動方法

静的HTMLのみなので、`index.html` をブラウザで開くだけで利用できます。

## 使い方（教授向け）

1. 画面右上で **「教授向け運用ページ」** を選択
2. 以下を入力して保存
   - OpenAlex Author ID（既定値: `A5069986511`）
   - Crossref 補助検索クエリ
   - Googleフォーム埋め込みURL
   - GoogleスプレッドシートURL（`/edit` 形式でも可）
   - 文献更新間隔（分）/ メッセージ更新間隔（秒）
3. **「第三者向けURLをコピー」** で共有

## メッセージ同期について

- 回答先スプレッドシートは「**ウェブに公開**」設定が必要です。
- スプレッドシートURLは内部でCSV API URLに変換して取得します。
