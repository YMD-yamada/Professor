# 群馬大学 吉原利忠教授 紹介ポータル

吉原教授（群馬大学大学院理工学府）の研究内容を伝える紹介ページです。  
**Googleフォームやスプレッドシートは不要**で、ページ単体でメッセージ運用ができます。

## できること

- **第三者向け**
  - 教授プロフィール、研究テーマ、経歴ハイライトを読みやすく表示
  - OpenAlex / Crossref から文献を自動取得して最新化
  - ページ内フォームから直接メッセージ投稿（ログイン不要）
  - 教授に渡すための「共有リンク」をワンクリック生成
- **教授向け**
  - 群馬大学の吉原教授アカウントでGoogleログインして管理機能を利用
  - 管理者（あなた）はGoogleログインで承認操作を実行
  - 共有リンク（または共有コード）を貼るだけでメッセージ取り込み
  - 受信メッセージを一覧表示
  - JSON/CSVのエクスポート
  - 全メッセージ削除（必要時）
  - 修正依頼キュー（承認後のみ自動反映）

## 起動方法

静的HTMLのみです。`index.html` をブラウザで開くだけで利用できます。

## 公開（GitHub Pages）

このリポジトリには `.github/workflows/deploy-pages.yml` を追加してあり、`main` ブランチ更新時に GitHub Pages へ自動デプロイされます。

1. GitHub リポジトリの **Settings > Pages** を開く
2. Source は **GitHub Actions** を選択
3. `main` へマージ後、Actions の `Deploy static site to GitHub Pages` が成功すれば公開完了

公開URL例:

- `https://<your-account>.github.io/<repository-name>/`

## 運用フロー（外部サービスなし）

1. 第三者が「第三者向け」画面でメッセージ入力
2. 「共有リンクをコピー」を押して教授へ送付
3. 教授が「教授向け管理」画面でGoogleログイン後にリンクを取り込み
4. 必要に応じてJSON/CSVでバックアップ

## ログイン方式と成りすまし対策

- 第三者はログイン不要で利用可能
- 教授向け管理操作は **群馬大学の吉原教授アカウントでのGoogleログイン後のみ** 実行可能
- 承認系操作（修正依頼の承認/適用）は **管理者Googleアカウントログイン後のみ** 実行可能
- 管理者アカウントは初回ログイン時に登録され、以後そのアカウントのみ承認操作を実行可能
- 教授投稿と第三者投稿を表示上で区別し、混同しにくい構成にしています

## Googleログイン設定（初回）

このページは Google Identity Services を利用します。公開前に Google OAuth クライアントID（Web）を準備してください。

1. Google Cloud で OAuth クライアントID（Web）を作成
2. 許可済みJavaScript生成元に公開URLを追加
   - 例: `https://ymd-yamada.github.io`
3. 許可済みリダイレクトURIが必要な場合は Pages URL を追加
4. `config.js` を開き、`googleClientId` に取得した Client ID を設定

```js
window.APP_CONFIG = {
  googleClientId: "YOUR_GOOGLE_CLIENT_ID"
};
```

### 本番向けの扱い

- `config.js` は **Client ID 専用** として分離してあります
- Google Client ID は秘密情報ではないため、静的サイトに置いて問題ありません
- アプリ本体 (`index.html`) を触らず、`config.js` のみ差し替えれば設定変更できます

## 教授からの修正依頼フロー（承認付き）

1. 教授ログイン後に「修正依頼」を登録
2. システムが自動で修正案（対象セクション + 反映文面）を生成
3. 管理者承認者が依頼を承認
4. 承認済み依頼のみ「自動反映」を実行
5. 反映履歴は依頼キューで状態管理（承認待ち/承認済み/適用済み/却下）

## 注意点

- メッセージはブラウザの `localStorage` に保存されます（端末単位）。
- 端末を跨いで自動同期するには、共有リンク取り込みを使ってください。
